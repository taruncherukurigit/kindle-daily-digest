decisions

cat design-decisions.log
[reliability]

No AI calls anywhere in the run path. An earlier version used Claude Code for search and synthesis, and a single run could burn through a usage window and fail silently. This one runs on fixed rules only: source weighting, per-feed caps, cross-category dedup, freshness sort.

[capacity]

Per-feed cap, not per-category. One high-volume feed could eat an entire category's budget by itself during testing. Capping the feed keeps any single source from crowding out the rest, the same reason you would not let one interface saturate a shared uplink.

[navigation]

Quick Skim links jump inside the epub. An e-ink Kindle often has no working browser. Every article carries its own anchor id, so the index jumps straight to the full text already sitting in the file.

[scope]

No images. RSS enclosure tags only covered a fraction of articles, and text extraction never returns images at all. A feature that half-works was worse than no feature.
